# Zero — why.zero.university (local clone)

A complete mirror of [https://why.zero.university/](https://why.zero.university/) —
the interactive WebGL/Three.js "Human Infrastructure to Get Hired" experience —
including every asset the site loads at runtime.

## What's here

- `index.html` — original page, one deviation: the Google Analytics snippet was
  removed so the clone doesn't phone home to the original site's GA property.
- `assets/` — all runtime assets, mirrored with their original filenames:
  JS/CSS bundles and code-split chunks, KTX2 texture atlases, GLB models,
  origami models + AO textures, audio, video, fonts, brand, UI, and logos.
- `vendor/basis/` and `vendor/draco/` — the KTX2 and Draco transcoders/decoders
  (fetched from the original site's `/vendor/` paths).

## Running it

The page uses root-absolute paths (`/assets/...`), so serve the directory root:

```bash
python -m http.server 8080
# then open http://localhost:8080/
```

Any static server works (nginx, `npx serve`, etc.).

## Notes

- The waitlist / "Join Beta" form posts to the original site's Supabase backend,
  which this clone can't reach; the form's error handling reports that instead.
- `mirror-download.sh` is the script that fetched every file — re-run it to
  refresh assets.

## MECHVERSE modification

The opening experience was modified (`mechverse-patch.py` reapplies it):

- The `99 → 0` loader counter is replaced with random 9-letter uppercase
  sequences that progressively resolve into **MECHVERSE** as assets load
  (canvas overlay, DOM loader, and the pre-paint placeholder).
- The drawing instruction is now **DRAW M**.
- The circle-drawing guide is replaced by an animated handwriting-style M
  guide (SVG stroke + pen dot + corner dots) plus a full-screen ink overlay
  that shows the user's own stroke while they draw.
- The stage's circle recognition is replaced by M recognition: the stroke is
  resampled, normalized, smoothed, and scored via extrema/valley analysis plus
  a DTW match against an M template. Incorrect shapes (lines, circles,
  scribbles, partial Ms) are rejected with a subtle red flash and the user
  stays on the stage; a recognizable M advances to the next stage exactly as
  the original circle did.
- The floating badge/coin logos around the hand (IBM, Apple, Windows, etc.)
  are replaced with a **MECHVERSE** mark: a dark-steel M+V+gear monogram
  derived from the project favicon, rendered as a texture on the existing
  white coin material so the coins keep their 3D orbit, spin, perspective,
  and depth exactly as before.
- A 9th badge carrying the **trendieez seahorse mark** is added at the head
  of the coin ring (index 0 — the first badge to appear), so the seahorse
  floats around the hand alongside the MECHVERSE coins. Both marks are
  generated by `make-coin-logo.py` into `assets/logos/mechverse-coin-dark.png`
  and `assets/logos/trendieez-logo.png`.

Reproducing the modification from the pristine mirror:

```bash
python make-coin-logo.py   # regenerates assets/logos/mechverse-coin-dark.png
python mechverse-patch.py  # rewrites index.html + the JS/CSS bundles
```
